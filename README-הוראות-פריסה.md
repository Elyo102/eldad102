# מדריך פריסה — דוח נוכחות כבאים (PWA)

המדריך הזה מניח שאין לך שום ידע קודם ב-Git או GitHub. כל שלב מוסבר עד הסוף.
בסיום תהיה לך אפליקציה אמיתית שאפשר להתקין על המסך הראשי בטלפון, גם ב-Android וגם ב-iPhone.

---

## חלק א׳ — עדכון ה-Apps Script (5 דקות)

זה הצעד היחיד שנוגע בשרת. אנחנו **לא** נוגעים בקובץ `Code.gs` הקיים — רק מוסיפים לו קובץ חדש שמדבר איתו.

1. פתח את הגיליון (Google Sheets) שבו רץ היום דיווח השעות.
2. תפריט **תוספים (Extensions)** ← **Apps Script**.
3. בעמודה השמאלית (רשימת הקבצים), לחץ על סימן ה-**+** ליד "קבצים" ← **סקריפט (Script)**.
4. תן לקובץ החדש את השם `Api` (זה ייצור אוטומטית קובץ בשם `Api.gs`).
5. פתח את הקובץ `Api.gs` שנוצר במחשב שלך (בתיקייה שקיבלת ממני) — תעתיק את כל התוכן שלו, ותדביק אותו בקובץ `Api.gs` שיצרת ב-Apps Script (מחליף את מה שהיה שם, אם היה ריק/דוגמת ברירת מחדל).
6. שמור (Ctrl+S / Cmd+S).
7. עכשיו צריך **לפרוס גרסה חדשה** כדי שהשינוי ייכנס לתוקף:
   - למעלה מימין: **Deploy** ← **Manage deployments**.
   - ליד הפריסה הקיימת (ה-Web App), לחץ על עיפרון העריכה (✎).
   - ב-"Version" תבחר **New version**.
   - לחץ **Deploy**.
8. ודא שהכתובת (ה-URL שמסתיים ב-`/exec`) **נשארה זהה** לזו שכבר נתת לי:
   `https://script.google.com/macros/s/AKfycbwHeYgUcSf13H1afd8aOjWIze1yhLXRlEjJNTtOyOVZGiYcnp_ch-stU3gLSppkpyLK/exec`
   אם ה-Deploy יצר כתובת **חדשה** — תגיד לי, ואני אעדכן את הקובץ `app.js` בהתאם (זו שורה אחת).

### בדיקה מהירה שזה עובד
פתח בדפדפן (בכל מחשב/טלפון) את הכתובת הזאת (שים לב ל-`?action=ping` בסוף):
```
https://script.google.com/macros/s/AKfycbwHeYgUcSf13H1afd8aOjWIze1yhLXRlEjJNTtOyOVZGiYcnp_ch-stU3gLSppkpyLK/exec?action=ping
```
אם אתה רואה טקסט כמו `{"success":true,"message":"API פעיל",...}` — השרת מוכן. אם רואים דף שגיאה, סימן שהפריסה לא הצליחה — חזור לשלב 7.

## חלק ב׳ — הקמת חשבון GitHub (אם אין לך)

1. גלוש ל-**github.com** ולחץ **Sign up**.
2. תבחר שם משתמש, מייל וסיסמה, ועבור את אימות המייל.
3. זהו — אין צורך להתקין שום תוכנה. נעבוד דרך האתר בלבד.

---

## חלק ג׳ — יצירת הריפו והעלאת הקבצים (ללא Git, דרך האתר)

1. אחרי ההתחברות ל-GitHub, לחץ על ה-**+** למעלה מימין ← **New repository**.
2. שם הריפו: למשל `dochshaot-102` (אפשר גם עברית, אבל מומלץ אנגלית כדי למנוע בעיות בכתובת).
3. השאר אותו **Public** (חובה כדי ש-GitHub Pages יעבוד בחינם).
4. **לא** מסמנים "Add a README file" (כדי שלא תהיה התנגשות בהעלאה).
5. לחץ **Create repository**.
6. בעמוד הריפו הריק, יופיע קישור **uploading an existing file** — לחץ עליו.
   (אם לא רואים אותו: לחץ **Add file** ← **Upload files**.)
7. גרור לתוך החלון **את כל התוכן** של תיקיית `pwa` שקיבלת ממני **חוץ מהקובץ `Api.gs`** (הוא כבר בשרת, לא שייך ל-GitHub):
   - `index.html`
   - `style.css`
   - `app.js`
   - `manifest.json`
   - `service-worker.js`
   - התיקייה `icons` (עם 4 קבצי ה-PNG)
   - קובץ המדריך הזה (אופציונלי)
   
   טיפ: אם אתה גורר תיקייה שלמה (`pwa`) מהמחשב, GitHub שומר את מבנה התיקיות הפנימי (`icons/...`) אוטומטית — זה מה שאנחנו רוצים.
8. למטה, בתיבת ה-commit message אפשר להשאיר את ברירת המחדל, ולחץ **Commit changes**.

---

## חלק ד׳ — הפעלת GitHub Pages (האירוח החינמי)

1. בריפו, היכנס ל-**Settings** (בתפריט העליון של הריפו).
2. בתפריט הצדדי השמאלי, לחץ **Pages**.
3. תחת **Build and deployment** ← **Source**, בחר **Deploy from a branch**.
4. תחת **Branch**, בחר `main` ותיקיית `/ (root)`, ולחץ **Save**.
5. חכה כדקה-שתיים, ורענן את העמוד. יופיע למעלה קישור ירוק בסגנון:
   `https://<שם-המשתמש-שלך>.github.io/<שם-הריפו>/`
6. זו הכתובת של האפליקציה שלך! שלח אותה לעצמך ותפתח אותה בטלפון.

## חלק ה׳ — התקנה על מסך הבית בטלפון

**אנדרואיד (כרום):**
פותחים את הקישור ← שלוש נקודות למעלה ← **הוספה למסך הבית / התקנת אפליקציה**.

**אייפון (ספארי — חובה ספארי, לא כרום):**
פותחים את הקישור בספארי ← כפתור השיתוף (הריבוע עם החץ) ← **הוסף למסך הבית**.

מהרגע הזה האפליקציה תיפתח כמו אפליקציה רגילה, עם אייקון, בלי סרגל כתובת של הדפדפן.

## עדכונים עתידיים

בכל פעם שתרצה לשנות משהו בעיצוב/בקוד של האפליקציה: פשוט חוזרים לריפו ב-GitHub, נכנסים לקובץ הרלוונטי, לוחצים על העיפרון (עריכה), עורכים ולוחצים **Commit changes**. תוך דקה-שתיים השינוי יופיע בכתובת החיה. את השרת (Apps Script) מעדכנים כמו בחלק א׳ למעלה.

## פתרון תקלות נפוצות

**"שגיאה בהתחברות" / מסך לבן אחרי כניסת קוד**
כנראה ה-Web App לא פרוס בגרסה עדכנית. חזור לחלק א׳, שלב 7 (Manage deployments ← New version ← Deploy).

**שגיאת CORS בקונסולת הדפדפן (`blocked by CORS policy`)**
ודא שב-Apps Script: Deploy ← Manage deployments ← "Execute as" מוגדר ל-**Me**, ו-"Who has access" מוגדר ל-**Anyone**. כל שינוי בהגדרות האלה דורש **New version** מחדש.

**האפליקציה לא מתעדכנת אחרי שינוי (בגלל שמירה במטמון)**
זה ה-Service Worker שומר גרסה ישנה. סגור לגמרי ופתח מחדש את האפליקציה, או: הגדרות דפדפן ← Developer Tools ← Application ← Service Workers ← Unregister, ואז רענון.

**שכחת את הקוד האישי בן 4 הספרות**
משתמשים בכפתור "שכחתי קוד אישי" במסך הכניסה — נשלח מייל לכתובת הרשומה במערכת.
